# GRC Compliance and Risk Management 

## Company Scenario
**Organization:** FinTechSecure Ltd.
**Industry:** Financial Technology (FinTech)
**Size:** Mid-sized enterprise (150 employees)
**Scope:** Cloud-based payment processing platform handling sensitive financial and personal data.

## Regulatory Framework
This project demonstrates alignment with the National Cybersecurity Authority (NCA) Essential Cybersecurity Controls (ECC).

## Core Components
- **Governance:** Establishing comprehensive policies for access control and data protection.
- **Risk Management:** Conducting continuous risk assessments to identify vulnerabilities.
- **Compliance:** Mapping technical controls to NCA standards and maintaining audit evidence.
